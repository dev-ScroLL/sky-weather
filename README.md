# Sky.

Sekiz dilde güncel hava durumu, 24 saatlik tahmin ve 7 günlük tahmin gösteren statik web sitesi.

## Çalıştırma

Klasördeki `index.html` dosyasını tarayıcıda açın. Hava durumu ve şehir araması için internet bağlantısı gerekir. Konum özelliği tarayıcı izni gerektirir. Yerel HTTP önizlemesi için bu klasörde `python -m http.server 8000` çalıştırıp `http://localhost:8000` adresini açabilirsiniz.
